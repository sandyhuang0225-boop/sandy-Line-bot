BeSure 活動申請小助理

從 Create Request 到 Submit Request · 依 2026／11／18 操作畫面整理

流程目錄

1. 建立申請2. 登錄外部專家與酬金3. 確認活動主責與聲明4. 活動資料、議程與擬聘人數5. 本次已選專家與聘請方式6. 活動形式與場地7. 餐旅費、酬金總額與報價單8. 外部與會者與跨國邀請9. 確認活動評估與標準合約10. 外部專家事前評估11. 風險緩解措施12. 檢查議程及補充附件13. 核對、送審與查詢14. 紅字與卡關排除

以三總乳癌討論會的填寫情境為例。活動類別、名單、費率、場地和審查人依本筆申請及公司現行指引確認。可用下方搜尋找英文欄位、中文解釋或錯誤訊息。

01建立申請New Request · General Information
Create Request
在 BeSure 首頁建立申請。進入表單後可在 Request Basic Details 核對申請編號，日後用同一筆編號查找草稿及送審狀態。
Choose Activity
依實際主辦方式及活動目的選類別。拿不準時點 Check your activity category here。照片沒有拍到展開後的選項，請依現行選單及公司分類說明選擇。
Organizational Unit / Requester
核對是否為 Taiwan 與你的申請帳號。Requester 是送件人，Activity Owner 是活動實際負責人。
Who is the Activity Owner?
自己負責就選 Myself；替其他同事建案就選 Another Associate，並依畫面指定負責人。核對 Activity Owner’s Department 是否正確，例如 Sales。
Estimated Total Cost Currency
本次預算以新台幣編列就選 TWD。金額欄出現時按本場預算填，和後續 Financials 的明細核對。
02登錄外部專家與酬金Fair Market Value · Add New Engagement
＋ Add New Engagement
在 Fair Market Value 按藍色按鈕。No FMV added 表示尚未新增紀錄。這裡登錄本場聘請的外部專家及服務費用。
Engagement Type / Country / HCP Tier
以台灣醫師為例選 HCP / Taiwan。Tier 依該醫師適用的公司 FMV 分級選擇。截圖案例顯示 Specialist: Tier 1 與每小時 TWD 5,000，此為該次畫面示例。
HCP identified yet?
已知擬聘醫師就選 Yes，於出現的名單中核對姓名與專科等資料，勾選正確的一列並點名單旁的 SAVE。尚未知道人選就依實況選 No，再依畫面提示填寫。
HCP threshold 提示
畫面會顯示國別門檻及該醫師當年度已核准的合作次數與金額。遇到接近門檻或提示時，看公司指引和系統後續要求。
Service Time
依實際提供服務的時間填 Hours／Minutes，並與議程角色、時段核對。
Preparation Time / Travel Time
點各欄下方 General and Local Guidance Notes，確認哪些時間可計入。截圖中交通時間上限是 0h 0m，因此該筆填 00 小時 00 分鐘。
Rate / Tax / Total Cost
上方 Hourly Rate 是每小時費率。Total Amount 區的 Rate 隨可計入的時間計算，Tax 按公司填寫規則處理，再核對 Total Cost 與合約金額。
Rationale for selection of the External Expert
此欄必填。交代醫師的相關專長、臨床經驗、與議題的關聯，以及這次受邀的角色。完成後依畫面儲存該筆，回 FMV 確認清單已出現紀錄。
以截圖費率試算

40 分鐘服務約 NT$3,333.33。若實際有 20 分鐘備課，且公司指引允許計入，合計 60 分鐘為 NT$5,000（畫面 Tax 為 0 的情境）。若有差額，核對合約、分級及時間，依實際可計入的工時申報。

03確認活動主責與聲明Acknowledgement
Will the event be co-owned by other Novartis functions?
Sales 單獨主責選 No。若 Medical 或其他諾華部門共同負責活動則選 Yes。出席、提供資料或協助審閱本身不代表共同主責。
跨部門活動
畫面要求清楚區分推廣性與非推廣性議程內容。依實際分工及公司指引核對。
Novartis Events must…
畫面提醒活動須具正當目的，聘請外部專家時至少有一位諾華同仁出席，並清楚告知參與者主辦方。虛擬或混合活動用公司核准工具。活動物品及內容審核依畫面列出的公司規定處理。
04活動資料、議程與擬聘人數Activity Details
活動資料
以本筆申請的最新議程核對活動名稱、日期、講者及角色。活動名稱和日期欄位的完整畫面未拍到，依實際表單填寫。
主辦方提示
議程、邀請函等資料要清楚標示實際主辦方。截圖提示由諾華主辦的活動應向與會者清楚揭露。
Upload agenda
按 UPLOAD 或藍色＋新增最新版議程，確認檔案已列出。之後可在 Request Documents 再核對。
How many External experts will be engaged?
填整場預計聘請提供專業服務的人數。受聘講者、主持人或主席依實際角色計入，一般出席者不計。畫面提醒醫療專業人員擔任主持／主席的人數不可超過講者人數。
Do you know already external experts suggested to be engaged?
擬聘人選已知選 Yes，再依實況選 External Expert 類別，例如 Healthcare Professionals (HCP)。如畫面要求，回 FMV 填姓名與資料。
05本次已選專家與聘請方式External Expert Questions
Total number of External Experts selected in this submission
填這次申請已選定的外部專家人數，與實際名單和 FMV 紀錄核對。這欄是本次已選定人數，前一欄是整場預計聘請人數。
Will any External Experts be engaged through a Third Party?
諾華直接聘請醫師、未經第三方，就選 No。若經代理商等第三方聘請，依欄下說明判斷。說明指出第三方須為非該 HCP 的雇主，且非該 HCP 直接擁有。
Is the HCP engaged to speak within their own institution?
依演講地點判斷。若是在醫師任職的醫院或診所內，選 Yes。若醫師在院外餐廳會場演講，選 No。
Is any External Expert’s country of practice different?
比較專家執業地與活動發起國。若活動由台灣發起且所有外部專家都在台灣執業，選 No。
06活動形式與場地Format and Venue
What is the format of event?
依實況選實體、線上或混合。實體場次找 In-person／Face-to-face 的對應項目，名稱以你看到的選單為準。
Type of venue
在餐廳舉辦可選 Restaurant。其他場地依實際類型選。
The detail of venue
必填。寫場地名稱、地點及實際選址理由，例如便於多數與會者抵達，空間能安排簡報與討論。按畫面指引考量場地適切性、費用、交通，以及娛樂或觀光場所限制。
Upload additional documents / Comments
場地佐證或說明有需要再補，依表單實際要求處理。
07餐旅費、酬金總額與報價單Financials
Travel, accommodation and hospitality cost breakdown
有餐費、交通、住宿預算時，按 ＋ Add New Row，依費用類型分列。Type of costs 選實際類別，Costs 填該筆預估總額，Comments 說明預算計算方式。
Meals and refreshments limits
截圖可讀到餐飲累計 NT$3,500／人／日與 Virtual Event Limit NT$500，金額包含稅、服務及配送費。單餐等其他限額請看當頁完整指引；按當次適用的上限核對。
External experts honoraria (total costs)
填完成 FMV 後所有外部專家的總酬金。若當次只有一位、FMV Total Cost 是 TWD 5,000，填半形 5000。餐飲與交通等按各自費用明細列。
Upload vendor/travel agent quotation, if any
有餐廳或其他廠商報價單，依欄位提示上傳。Upload additional documents, if needed 可加上其他佐證。
禮品提示
畫面提醒不得提供禮品予 HCP、HCO、病友組織、病人及其家屬，亦不鼓勵提供給其他利害關係人。
08外部與會者與跨國邀請Participants and Attendees
Select type of external stakeholders and audience
依實際邀請對象選類別。若外部與會者是醫療專業人員，選 Healthcare Professionals (HCP) 或畫面對應的類別。
Describe external stakeholders and audience
寫預計邀請的院所、科別或職類，以及這群人的工作如何與活動主題相關。科別按實際名單調整。
Is it planned to invite any HCPs from outside their country of residence or practice?
台灣活動若未計畫跨國邀請 HCP，就選 No。有跨國邀請時依實況作答並查看後續欄位。
External participants 提示
對象應和議題相關。若擬邀請曾參加同主題諾華活動的人員，畫面要求有合理理由。
09確認活動評估與標準合約Activity Assessment
Assess to ensure…
依活動實況檢視醫學、科學、教育及／或臨床內容的適切性與品質，完成適用的檢視再勾選。
Adverse event reporting
若活動中可能得知疑似不良事件，畫面提醒依公司內部流程通報。
Confirm that you will be using a standard contract template…
這題問是否採用包含所有必備條款的公司標準合約。若確認採用適用版本並保留條款即可選 Yes。可從當頁標準範本連結核對；用合約生成器產出的文件也要核對版本與條款。
10外部專家事前評估Expert Assessment
Were the HCPs pre-assessed by the Medical function?
此題問 Medical 是否直接完成事前評估。已確認完成選 Yes；未由 Medical 直接評估選 No，並查看是否出現後續欄位。
Medical 預核標準
畫面指出亦可依 Medical 預先核准的標準評估。若走這條路，確認已依適用標準完成並遵循後續要求。
紀錄未確認
按 Save as Draft，向負責同事確認適用的評估方式與紀錄，再回原申請繼續。FMV 資料用來核算酬金。
11風險緩解措施Mitigation Actions
Mitigation actions plan (if necessary)
前面評估完成且沒有需要額外處理的事項時，可留空並按 Next。有需處理的事項，記錄具體措施、負責人及完成時間。
評估結果不清楚或不完整
畫面指示諮詢相關風險職能。可先存草稿，補齊評估及處理方式後繼續。

14紅字與卡關排除常見問題
The value provided is not an integer
先清空人數欄。切至 ENG 英文鍵盤再打半形數字，例如一位填 1（全形為１）。按 Tab 離開欄位。如果英文鍵盤切不過去，可直接貼半形數字。仍有紅字先存草稿，確認成功後從 Requests 重開同一筆；持續報錯請附申請編號和錯誤文字給公司 BeSure 支援。
Time for engagement cannot exceed 0h 0m
先看紅字出現在哪個欄位。截圖出現在 Travel Time，這筆上限為 0 小時 0 分鐘。改回 00／00，再核對 Total Cost。
金額不一致
核對 HCP Tier、Hourly Rate、實際可計入時間與 Tax。再比較 FMV Total Cost、Financials 酬金總額和合約。
看不到下一步或不確定是否存好
往頁底找 Next／Save as Draft。若已保存，從 Requests 看同一筆申請。草稿尚未保存時，先保留表單畫面。
